大脑分层设计与数据走向

1. 摘要层 (Summaries): 实时捕获近期发生的群聊上下文，作为极短期的碎片化群快照，当摘要生成后可由人工手动切断其对全局事实的潜在影响。

2. 新闻层 (News Entries): 将零散的群摘要中涉及的重要社会事实提取并巩固，升级为跨群流传的"全局社会新闻"，达到遗忘阈值后将自动被淘汰。

3. 人物层 (Persona Profiles): 当全局事实新闻因衰减淘汰被物理擦除时，涉及人物的性格特写与偏好变化，会被二次沉淀进其终身性格档案中。
